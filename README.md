  <h1>🧠 Programming Language Paradigms</h1>
  <p><strong>Author:</strong> João Pedro Soares</p>

  <h2>📌 Description</h2>
  <p>This repository contains practical examples and exercises developed during the course on <strong>Programming Language Paradigms</strong>. The goal is to explore different programming paradigms including imperative, functional, logic, and object-oriented programming.</p>

  <h2>📁 Contents</h2>
  <p>The repository includes examples and implementations in different paradigms:</p>
  <ul>
    <li><strong>Imperative Programming:</strong> Procedural logic, control structures, and state changes.</li>
    <li><strong>Functional Programming:</strong> Use of immutability, pure functions, and higher-order functions.</li>
    <li><strong>Logic Programming:</strong> Representing facts and rules, exploring Prolog-style logic.</li>
    <li><strong>Object-Oriented Programming:</strong> Classes, objects, inheritance, and encapsulation.</li>
  </ul>

  <h2>🛠️ Technologies Used</h2>
  <ul>
    <li>Java</li>
    <li>Python</li>
    <li>Prolog</li>
    <li>Haskell (if included)</li>
  </ul>

  <h2>🚀 How to Use</h2>
  <ol>
    <li>Clone the repository</li>
    <li>Open the folders by paradigm or language</li>
    <li>Run the code in your IDE or interpreter for each language</li>
    <li>Explore and compare how each paradigm approaches problem solving</li>
  </ol>

  <h2>🎯 Educational Purpose</h2>
  <p>This project aims to help students and enthusiasts understand the core principles of each programming paradigm and how they differ in terms of syntax, semantics, and design philosophy.</p>
